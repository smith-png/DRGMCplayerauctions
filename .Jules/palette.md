## 2024-04-26 - Added ARIA Labels to Icon-Only Buttons
**Learning:** Found several instances across the app (modals, overlays, team expanding buttons, player release buttons) where interactive buttons contained only icons (e.g., `✕`, `×`, `+`, `-`) without any descriptive text. This is a common accessibility issue that makes it difficult for screen reader users to understand the button's purpose. Even if a `title` attribute is present, it is not consistently read by all screen readers.
**Action:** When implementing or modifying icon-only buttons (especially toggles and dismiss actions), always include a descriptive `aria-label` attribute (e.g., `aria-label="Close modal"` or `aria-label="Collapse team details"`). For toggle buttons, also use `aria-expanded` to communicate the current state.
