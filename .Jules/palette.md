## 2026-04-11 - Custom Role Selector Accessibility\n**Learning:** When using custom div/button groups instead of native select elements for form inputs (like the Access Role selector), screen readers lose the context. It requires `role="group"`, an associated label with `aria-labelledby`, and `aria-pressed` on individual buttons to correctly expose state and relationships.\n**Action:** Always verify custom selector implementations include proper ARIA roles and state attributes.
