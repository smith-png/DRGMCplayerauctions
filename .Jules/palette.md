## 2024-05-24 - Interactive Menus Should Be Buttons
**Learning:** In the DRGMC Player Auctions app, the Navbar contained a profile/user information area implemented as a simple `<div>` with an `onClick` handler. This is a common pattern that completely excludes keyboard-only and screen reader users from accessing account functions. While this generic pattern is common, replacing `div`s with `button`s in custom UI menus is critical because standard inputs like buttons naturally trigger `focus-visible` and Space/Enter interactions, requiring much less polyfilling for basic accessibility.
**Action:** When creating custom popover menus or tooltips triggered by a user's icon or profile name, always use `<button>` instead of `<div>` or `<span>`, and ensure they have `aria-expanded` and `aria-haspopup` to properly communicate their function to assistive technologies.
