## 2026-07-08 - Accessible Links and Interactive States\n**Learning:** In React applications, using `<span>` elements with `onClick` for navigation creates accessibility barriers (no keyboard focus, no screen reader context). Additionally, toggle buttons (like password visibility) need dynamic `aria-label`s or `aria-pressed` states to communicate their status to assistive technologies.\n**Action:** Always prefer semantic HTML (like `<a>` or React Router's `<Link>`) for navigation. Ensure interactive elements without visible text labels have `aria-label` attributes, and use `aria-pressed` for stateful toggle buttons.
