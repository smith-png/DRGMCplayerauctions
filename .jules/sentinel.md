## 2024-05-18 - [Missing Authorization Checks in Bidding Endpoint]
**Vulnerability:** The `/bid` endpoint lacked proper authorization checks. Although the route was protected by `authenticateToken`, which ensured the user was logged in, the `placeBid` controller did not verify that the user was either an admin or the owner of the team (`teamId`) for which the bid was being placed. This IDOR (Insecure Direct Object Reference) allowed any authenticated user to place bids on behalf of any team, draining their budget or winning players maliciously.
**Learning:** In a multi-tenant or role-based system, authenticating the user is not enough. You must explicitly authorize the action by validating that the authenticated user owns or has permission to act on the specific object (e.g., `teamId`) they are interacting with.
**Prevention:** Always implement object-level authorization checks in controllers or middleware before modifying state. Compare the `teamId` from the request against the `req.user.team_id` or check if `req.user.role === 'admin'`.
