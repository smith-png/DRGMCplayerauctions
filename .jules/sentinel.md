## 2024-05-19 - IDOR Fix in Auction Controller\n**Vulnerability:** Insecure Direct Object Reference (IDOR) allowed team owners to place bids for other teams via the API because 'teamId' from the payload was not validated against 'req.user.team_id'.\n**Learning:** In a multi-tenant or multi-team application, object IDs received from user input must always be explicitly validated against the user's authorized IDs stored in the session/JWT.\n**Prevention:** Ensure backend handlers enforcing role-based permissions verify that users claiming ownership actually own the entity being mutated.
