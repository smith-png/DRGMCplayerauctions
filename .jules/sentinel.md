## 2024-05-17 - Fix Authorization Bypass in Bidding Endpoint
**Vulnerability:** The `/api/auction/bid` endpoint (`placeBid` in `backend/src/controllers/auctionController.js`) did not verify if the requesting user was authorized to place a bid for the specified `teamId`. Any authenticated user could place a bid on behalf of any team by simply changing the `teamId` in the request payload.
**Learning:** This is an Insecure Direct Object Reference (IDOR) or Broken Object Level Authorization (BOLA) vulnerability. Even if an endpoint requires authentication (e.g., via `authenticateToken`), it must also verify that the authenticated user has permission to perform the requested action on the specific resource referenced in the request.
**Prevention:** Always validate that the user has the required permissions and/or ownership rights for any identifier (like `teamId`) provided in the request body, parameters, or query string, before processing the request. In this case, `req.user.role` and `req.user.team_id` from the decoded JWT token are used to authorize the action.
