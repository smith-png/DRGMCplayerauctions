## 2024-05-18 - [Fix Authorization Bypass in Auction Bidding]
**Vulnerability:** The `/api/auction/bid` endpoint lacked an authorization check in `placeBid` in `backend/src/controllers/auctionController.js` to verify if the authenticated user has permission to bid on behalf of a specific team (`teamId`). This allowed any authenticated user to place a bid using another team's ID, which is an Insecure Direct Object Reference (IDOR) leading to authorization bypass.
**Learning:** Always ensure that an authenticated user has explicit authorization or ownership over the resources (like a team's budget/bids) they are attempting to manipulate, even if they are successfully authenticated to the application.
**Prevention:** In functions modifying resource states for specific entities, add checks ensuring `req.user.role === 'admin'` or the appropriate specific ownership relationship (e.g., `req.user.team_id === teamId` and `req.user.role === 'team_owner'`) before proceeding with the transaction.
