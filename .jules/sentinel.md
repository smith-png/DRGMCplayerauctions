## 2024-05-15 - [Authorization Bypass / IDOR in Bidding Logic]
**Vulnerability:** In `backend/src/controllers/auctionController.js`, the `placeBid` endpoint did not verify if the authenticated user making the request actually had the right to place a bid on behalf of the `teamId` provided in the request body. An authenticated user (e.g., a simple `viewer`) could spoof the `teamId` and place bids using another team's budget.
**Learning:** Even if an endpoint is protected by general authentication (`authenticateToken`), specific object-level or action-level authorization checks are required. It's critical to tie the action payload (`teamId`) to the authenticated user's identity (`req.user.team_id`) when state changes are involved.
**Prevention:** Always validate that the user has explicit permission for the specific entity they are acting upon. If an action requires a specific role or ownership, check `req.user.role` and `req.user.team_id` against the request payload.
