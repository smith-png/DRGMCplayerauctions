## 2024-07-01 - [Memoize Sorted Players]\n**Learning:** Found a component `PlayerProfiles` sorting `allPlayers` inline inside the render loop every time it re-renders. This is an O(n log n) operation run synchronously during rendering which can block the main thread for large lists.\n**Action:** Extract sorting into a `useMemo` hook to only recalculate when `allPlayers` or `playerSortBy` changes.
