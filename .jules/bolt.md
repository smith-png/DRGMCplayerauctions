## 2024-05-24 - Inline List Sort Operations on Render
**Learning:** Found an inline `[...allPlayers].sort(...)` operation in `frontend/src/pages/PlayerProfiles.jsx` that was executing an expensive O(N log N) re-sort on every component render. Since the list can be large and the component relies on real-time sockets (potentially causing frequent renders), this is a significant bottleneck. Also discovered a syntax error in `frontend/src/pages/AuctionStats.jsx` that broke the build, reminding me to always verify the build before pushing optimizations.
**Action:** Always wrap expensive data transformations (like `.sort()`, `.filter()` on large arrays, or complex nested `.reduce()`) inside `useMemo` hooks to prevent unnecessary recalculations on each render, especially in components tied to real-time updates. Check for basic syntax errors when inheriting new code.
